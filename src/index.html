helmoci

Any classic Helm chart repo, served as OCI. No helm repo add — pull by path.

helm pull oci://helmoci.tuananh.net/argoproj.github.io/argo-helm/argo-cd --version 7.7.12

Path mapping

Last segment is the chart name. Everything before becomes https://… for the classic repo.

Classic helm repo add argo https://argoproj.github.io/argo-helm
helm pull argo/argo-cd --version 7.7.12
Via helmoci helm pull oci://helmoci.tuananh.net/argoproj.github.io/argo-helm/argo-cd --version 7.7.12

Examples

# Argo CD
helm pull oci://helmoci.tuananh.net/argoproj.github.io/argo-helm/argo-cd --version 7.7.12
helm show values oci://helmoci.tuananh.net/argoproj.github.io/argo-helm/argo-cd --version 7.7.12

# cert-manager
helm pull oci://helmoci.tuananh.net/charts.jetstack.io/cert-manager --version v1.16.2

# latest (uses tags/list)
helm pull oci://helmoci.tuananh.net/argoproj.github.io/argo-helm/argo-cd

# crane
crane ls helmoci.tuananh.net/argoproj.github.io/argo-helm/argo-cd | head
crane manifest helmoci.tuananh.net/argoproj.github.io/argo-helm/argo-cd:7.7.12

# list versions
curl -s https://helmoci.tuananh.net/v2/argoproj.github.io/argo-helm/argo-cd/tags/list | jq '.tags[:5]'
